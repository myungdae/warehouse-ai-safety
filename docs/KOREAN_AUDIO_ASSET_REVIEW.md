# Korean Audio Asset Review

Twenty Korean PCM WAV candidates were generated offline with the locally installed `Microsoft Heami Desktop` (`ko-KR`) Windows voice. The manifest records exact catalog text, SHA-256, size, duration, format and generation method.

Automated status: `DEVELOPMENT_KOREAN_AUDIO_CANDIDATE`.

Human audibility status: `NOT_YET_REVIEWED`.

For each message, a human must confirm the correct Korean sentence, audible level, lack of clipping/distortion, overlap/preemption, cooldown, mute/unmute, cancel and ACK suppression. Playback completion alone is not audible evidence. No microphone, recording, cloud TTS or external network service is used.
